# LEWKIT

Repository of well planned primitives to be used in other projects.

Rushed code is not sustainable long term and this is our tool of reuse.

Test helpers live in `x/test`. Database open and migrate stay in `x/db`. CLI is `x/cmd`. Filesystem names are `x/path`. UDF, WIM, ZIP, tar, and SquashFS filesystems are `x/fs/udf`, `x/fs/wim`, `x/fs/zip`, `x/fs/tar`, and `x/fs/squashfs`.
