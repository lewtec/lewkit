# LEWKIT

Repository of well planned primitives to be used in other projects.

Disassembly is `x/disasm`: Capstone hosted in wazero. `lewkit disasm hex`, `lewkit disasm raw`, and `lewkit disasm file` print instructions.

Rushed code is not sustainable long term and this is our tool of reuse.

Test helpers live in `x/test`. Database open and migrate stay in `x/db`. CLI is `x/cmd`. Directed graphs are `x/graph` (DOT, Mermaid). Task trees with resource pools are `x/taskgroup`. Host capability selection is `x/driver`; a resizable window is `x/driver/window` (`Frame` / `Draw` swap, `Animate` ticks a paint func, `Subscribe` yields Resize/Expose/Close/Pointer/Scroll/Key). Compute GPUs are `x/driver/vulkan` (`Open` / `List`, vendor slugs). ndarray evaluators are `x/driver/ndeval` (CPU, Vulkan wrapping the selected GPU). The RGB triangle is `x/image.TriangleTurn`. `lewkit experiments window triangle` opens a window and animates it. `lewkit experiments window compute` does the same with `example.comp` (or a `.spv`/`.comp` path; `--smoke` prints the 4-byte probe). `lewkit doctor` lists drivers as interface => implementation. Event buses are `x/event` (`CreateTimer` is a ctx tick channel). A locked OS-thread job queue is `x/thread` (`thread.Run` from main). Cgo-free `dlopen` is `x/ffi`. Embedded WASM (wazero) is `x/wasm`. N-d views and a fused 21-op kernel compiler are `x/ndarray` (`Tensor` holds the op tree; `Eval` takes an `Evaluator`; `Open` picks ndeval Vulkan or CPU). Layers are `x/ndarray/nn`. Drawing is `x/ndarray/image` (fused `Triangle` / `Fill` over (h,w,4)). Pixel-frame TEA (bubbletea Init/Update/View, View is a layout Node, `Run` paints it) is `x/ui/gui` (CPU Box/Flex/Stack layout, one rounded-rect kernel plus an ink overlay for glyphs). `lewkit experiments window scroll` loops translucent boxes. `lewkit experiments window notepad` is an unsaved editor. `lewkit experiments window counter` is +/− on an int. Compute on Vulkan is `x/ffi/vulkan` (`Open`, `Buffer`/`Alloc`, `Shader`/`Compile`, `Run`, or `Begin`/`Bind`/`Push`/`Dispatch`/`Copy`/`Barrier`/`Submit`/`Wait`). `Shader` takes SPIR-V. Vulkan GLSL is compiled by `x/wasm/glsl` (`Load`) at the CLI.  Filesystem names are `x/path`. Name predicates are `x/path/pick`. Stream codecs are `x/compression` (gzip, brotli, lz4, zstd, xz, bzip2). Container listings are `x/fs.Files`; `x/fs.New` indexes a listing into `io/fs`. `x/fs.Copy` writes a listing into a dest. `x/fs.Walk` turns an `io/fs` into a listing. UDF, WIM, ZIP, tar, and SquashFS adapters are `x/fs/udf`, `x/fs/wim`, `x/fs/zip`, `x/fs/tar`, and `x/fs/squashfs`.
